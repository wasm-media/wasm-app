# wasm-app
تطبيق وسم ميديا — الشغلات ومراحلها، ثم المهام وعروض الأسعار والمحاسبة.

- `supabase/migrations/` — قاعدة البيانات (كل القواعد تُفرض في السيرفر).
- `web/` — الواجهة (لوحة الشغلات).
- `tests/` — الاختبارات: `sql/` و`ui/` و`ci/`. الحد الأدنى لعددها في `tests/COUNT`.
- `docs/` — بروتوكول البناء والمراجعة، الثوابت، القرارات، الأخطاء المسجلة، تعريفات الشرائح والحزم.
- `.github/workflows/release.yml` — النشر بعد الدمج في `main`: الترحيلات، ضبط Auth الإنتاج، نشر اللوحة على GitHub Pages، فحص قراءة فقط، روابط الدخول الأولى. في بيئة `production` بموافقة عيسى.
- `.github/workflows/backup.yml` — نسخة يومية مشفّرة إلى المستودع الخاص `wasm-app-backups` مع استعادة تجريبية.
- الأقفال: لا دفع مباشر على `main`؛ كل تغيير PR يمرّ من `ci` و`guard` وموافقة عيسى (CODEOWNERS).
